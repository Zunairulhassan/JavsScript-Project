# JavaScript Social Media UI Project

This is a **modern, responsive social media UI** built using HTML, CSS (with CSS variables), and vanilla JavaScript. It features dynamic components such as a customizable theme, interactive sidebar, notification popups, and a responsive layout for desktop and mobile.

## 🚀 Features

- ✅ Responsive layout using CSS Grid and Flexbox
- 🎨 Theme customization:
  - Change primary color
  - Change font size
  - Change background theme (Light, Dim, Lights Out)
- 🔔 Interactive sidebar menu with notification counters
- 📬 Functional message section with search filter and online indicator
- 🧾 Modular and maintainable code using CSS variables
- 🖼️ Stories and Feed sections styled like a real social app

## 🛠️ Technologies Used

- HTML5
- CSS3 (Custom Properties)
- JavaScript (Vanilla)
